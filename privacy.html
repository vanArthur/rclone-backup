Privacy policy

Last updated: 26 October 2026

rclone-backup is a personal tool used only by its owner to back up their own computer to their own Google Drive.

What data it accesses

It uses the Google Drive drive.file scope, so it can only see and manage files that it created itself. It cannot read any other files in the Google Drive.

How data is used

Backup data is encrypted on the owner's computer before it is uploaded and is stored only in the owner's Google Drive. No data is sent to, stored on, or shared with any other server or third party. No analytics or tracking are used.

Google API Services

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact

Questions can be raised via GitHub issues.
